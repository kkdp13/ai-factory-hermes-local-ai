  6. ห้ามใช้ผลลัพธ์ H3 ไปเทรนโมเดลอื่น (§V.3) เช่น เทรน Wan LoRA จากคลิป H3
  7. ถ้าใช้ H3 กับใบหน้าคนจริง (R2V) ยังต้องมีหนังสือยินยอมตาม PDPA

เรื่องหน้าเอกสาร ComfyUI: docs.comfy.org เขียนว่า "Commercial use of locally generated outputs requires a MiniMax commercial license" · ขัดกับตัว LICENSE (§II ให้สิทธิ์ royalty-free · §IV.1 ขออนุญาตเฉพาะเมื่อรายได้เกิน $20M) · ขัดกับหน้า comfy.org/minimax/license (ส.ค. 2026: "generally permits commercial use, provided … no more than $20 million") · และขัดกับ staff · law สรุป: ไม่ต้องซื้อ license ต่ำกว่า $20M ในพื้นที่ที่อนุญาต

7 · จำหน้า / LoRA

3 ทาง

ทางรายละเอียดสถานะ
1. LoRA บนโมเดลภาพ → keyframe → Wan I2V (แนะนำ)FLUX.2 klein base 4B หรือ Z-Image base · เทรนด้วย AI-Toolkit หรือ musubi-tuner บน Windows · BFL: 1500–3000 steps, "1-3 hours on consumer GPUs" (การ์ด 12 GB) · ผู้ใช้ 3060 รายงาน 512px 2–3 ชม. / 1024px 6–7 ชม.ไม่มีใครวัดบน 5070
2. Wan 2.2 LoRA ตรงๆเป็นไปได้แต่เปราะบน 12 GB · กรณีที่พบ (4070 + 64 GB) ล้มเลิกหลัง 3 วัน · ควรเป็นการทดลอง 1 วัน ไม่ใช่แผนผลิตยังไม่มีกรณีสำเร็จที่มีเวลา
3. ไม่เทรน (reference)FLUX.2 klein multi-reference · Wan-Animate-2 · H3 R2V (ใบหน้าคนจริงต้องมี consent)เหมาะกับหน้าแบบครั้งเดียว
แผนแนะนำ: LoRA สำหรับตัวละครหลักที่กลับมาทุกตอน · multi-reference สำหรับหน้าที่ใช้ครั้งเดียว (เป็นข้อเสนอของ vegapunk ยังไม่มี benchmark)

เทรนเนอร์

  • musubi-tuner: Wan2.2 เฉพาะรุ่น 14B ("only for 14B models") · "Windows compatibility confirmed" · RAM แนะนำ 64 GB ขึ้นไป · ใช้ --blocks_to_swap ทีละ expert (Windows ถ้าใช้ --offload_inactive_dit ต้องใช้ RAM ~96 GB จึงไม่เหมาะ 64 GB)
  • AI-Toolkit: รองรับ Wan2.2 T2V-A14B / I2V-A14B / TI2V-5B, Z-Image, FLUX.2 klein base 4B · รันบน Windows · "Webp currently has issues"
  • diffusion-pipe: ต้องใช้ WSL2 ("difficult or impossible … on native Windows") · 5B ทำได้เฉพาะ t2v/t2i

สูตรชุดรูปเทรน

  • รูปคมชัด 20–30 รูป (ตัวเลขจากชุมชน) · ~50% ใบหน้า–ไหล่ · 30% ครึ่งตัว · 20% เต็มตัว · หน้าตรง / เฉียง ซ้าย-ขวา / ด้านข้าง / ก้ม-เงย
  • แสงอย่างน้อย 3 แบบ · เปลี่ยนชุด/ฉากหลัง · ไม่มีแว่นกันแดดหรือฟิลเตอร์ · ต้นฉบับ ≥1024px
  • แคปชั่น = โทเคนหายาก + ชนิด (เช่น "ohwx woman") + เสื้อผ้า/ฉาก/ท่า · ไม่บรรยายใบหน้า
  • ทดสอบที่ 512 ก่อน แล้ว 768/1024 · ชุดข้อมูล Wan ≤ 960×544 · เทรนบน base แล้วเจนด้วย Turbo/distilled + LoRA

ห้ามใช้เชิงพาณิชย์ + กฎหมาย

  • PuLID / InstantID ห้ามใช้ทำโฆษณาที่ขายจริง: ใช้โมเดล InsightFace ซึ่ง "available for non-commercial research purposes only" (รวมที่ดาวน์โหลดอัตโนมัติ) · license MIT ของ node ไม่ช่วยแก้
  • PDPA ม.26: ข้อมูลชีวมิติเป็นข้อมูลอ่อนไหว ห้ามเก็บโดยไม่มี "explicit consent" รวม "facial recognition data" (ใช้คำแปลไม่เป็นทางการ ยังไม่เปิดฉบับราชกิจจาฯ) · LoRA ที่สร้างให้จำหน้าหนึ่งคน น่าจะ เข้าข่าย (ตีความ ยังไม่มีแนวปฏิบัติ PDPC) · ขอ consent เป็นลายลักษณ์อักษร
  • พ.ร.บ.คอมพิวเตอร์ ม.16 (แก้ไข 2560): ภาพของผู้อื่นที่ตัดต่อ/ดัดแปลงด้วยวิธีอิเล็กทรอนิกส์ จนน่าจะทำให้เสียชื่อเสียง ถูกดูหมิ่น เกลียดชัง หรือได้รับความอับอาย → จำคุกไม่เกิน 3 ปี ปรับไม่เกิน 200,000 บาท · ห้ามทำ LoRA คนดังหรือคนแปลกหน้า
  • สคบ. (OCPB) ตามบทความ Tilleke & Gibbins 12 มี.ค. 2026: ประกาศแนวทางโฆษณาที่สร้างด้วย AI มีผลแล้ว · ป้ายตัวอย่าง "Image created by AI" / "Video created by AI" ต้องเห็น/ได้ยิน/อ่านได้ชัด · ใช้ป้ายนี้ทุกคลิปเป็นค่าเริ่มต้น
  • ฟอร์ม consent ควรมี: วัตถุประสงค์ (เทรน AI + โฆษณา/ละครที่สร้าง) · แพลตฟอร์ม · ระยะเวลา · การถอนความยินยอม + ลบชุดรูปและ LoRA
